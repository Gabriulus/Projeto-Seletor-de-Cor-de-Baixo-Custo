# Projeto-Seletor-de-Cor-de-Baixo-Custo
Sistema automatizado de baixo custo de braço robótico separador de objetos po cor com esteira transportadora

Equipamentos: Arduino UNO R3, Sensor de COR TCS-3200, Módulo Relé 5V 10A, 3 Servo Motores SG90 9g e Extensão Shield V5.0.  
Detalhes de contrução, algorítmo e teoria aplicada, estão presentes no artigo submetido à revista princípia em anexo.
